The app uses the mobile website's Fraunces, IBM Plex Sans, and IBM Plex Mono fonts.
Sources: https://github.com/google/fonts/tree/main/ofl/fraunces,
https://github.com/google/fonts/tree/main/ofl/ibmplexsans, and
https://github.com/google/fonts/tree/main/ofl/ibmplexmono.

NLDisplay and NLBody are renamed static instances of the upstream variable fonts
at weights 400, 500, 600, and 700. Fraunces uses optical size 23, SOFT=0, WONK=1;
IBM Plex Sans uses width 100. IBM Plex Mono files are unchanged upstream assets.
